    What you are seeing

    The full FlyWire v783 connectome: 138,639 leaky integrate-and-fire neurons and 15,091,983 connections, weighted by synapse count and signed by neurotransmitter, with Shiu et al.'s constants. A set of sensory neurons gets Poisson input at 150 Hz for one simulated second, at a 0.1 ms time step. The faint cloud shows 20,000 randomly chosen neurons for orientation.

    Scrambled wiring uses the same neurons and synapse weights, but every connection's target is shuffled. Each neuron keeps its in-degree, out-degree and outgoing weights. The input no longer reaches the feeding motor neuron MN9. It spreads into unrelated olfactory and visual neurons instead.

    Reproduce it

    git clone https://github.com/recurse-root/ascend
cd ascend && pip install -e ".[test]"
python scripts/fetch_data.py
python scripts/fetch_data.py --group provenance
python scripts/make_demo.py

    Runs use the CPU float64 engine, which matches the Brian2 reference model spike for spike for the same input, with kick seed 0. The output is deterministic.
